# Discord бот регистрации участников

Публикует сообщение со списком участников и кнопками
**«Зарегистрироваться»** / **«Отменить регистрацию»**. Всё разворачивается
через Railway — ничего запускать на своём компьютере не нужно, включая
регистрацию слэш-команд: бот делает это сам при каждом старте.

## Шаг 1. Discord Developer Portal

1. Откройте https://discord.com/developers/applications → **New Application**, дайте любое имя.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен (это `DISCORD_TOKEN`). Здесь же включите **Message Content Intent** не обязательно — бот его не использует.
3. Вкладка **General Information** → скопируйте **Application ID** (это `CLIENT_ID`).
4. Вкладка **OAuth2 → URL Generator**: отметьте `bot` и `applications.commands`, ниже в Bot Permissions — `Send Messages` и `Embed Links`. Скопируйте появившуюся ссылку внизу, откройте её в браузере и выберите свой сервер — так бот попадёт на сервер.

## Шаг 2. Узнать GUILD_ID и (опционально) CHANNEL_ID

В Discord: **Настройки пользователя → Расширенные → Режим разработчика** (включить).
Затем:
- ПКМ по иконке сервера → **Копировать ID сервера** → это `GUILD_ID`
- (Не обязательно) ПКМ по конкретному каналу → **Копировать ID канала** → это `CHANNEL_ID`, если хотите, чтобы регистрация всегда публиковалась в один и тот же канал

## Шаг 3. Деплой на Railway

1. Загрузите эту папку в репозиторий на GitHub (или перетащите прямо в Railway — см. ниже).
2. На https://railway.app → **New Project → Deploy from GitHub repo** → выберите репозиторий.
   - Альтернатива без GitHub: **New Project → Empty Project**, затем в сервисе используйте **Deploy → Deploy from local directory** и загрузите папку через Railway CLI (`railway up`).
3. Откройте созданный сервис → вкладка **Variables** → добавьте:
   ```
   DISCORD_TOKEN=...
   CLIENT_ID=...
   GUILD_ID=...
   ```
   `CHANNEL_ID` — добавьте только если нужен фиксированный канал.
4. Railway сам пересоберёт и запустит сервис после сохранения переменных.

## Шаг 4. Проверка

Вкладка **Deployments → View Logs**. Если всё верно, увидите:
```
✅ Бот вошёл в систему как ИмяБота#1234
✅ Слэш-команды /setup и /reset зарегистрированы на сервере
🤖 Бот полностью готов к работе.
```
Бот появится онлайн в Discord. Идите на сервер и введите `/setup`.

### Если в логах ошибка

- `Не заданы переменные окружения: ...` — значит в Variables на Railway чего-то не хватает или опечатка в названии переменной.
- `Не удалось войти в Discord` — неверный `DISCORD_TOKEN` (скопируйте заново через Reset Token).
- `Не удалось зарегистрировать команды` — неверный `CLIENT_ID` или `GUILD_ID`.

## Команды

- `/setup [название] [канал]` — публикует сообщение регистрации. Право «Управление сервером» обязательно.
- `/reset` — очищает список участников. Тоже требует «Управление сервером».

## ⚠️ Про хранение списка

Список участников лежит в файле `data/registrations.json` на диске
контейнера. На Railway диск **эфемерный** — при каждом новом деплое
(например, `git push`) список обнулится. Если это важно, подключите
**Railway Volume** (Settings сервиса → Volumes) и примонтируйте его на
`/app/data` — тогда список переживёт передеплой.
